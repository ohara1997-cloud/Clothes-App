# Wireframes (low fidelity)

Phone width. These show layout and content only, not visual style. They will be turned into clickable mockups once requirements are agreed.

## Screen list

1. Sign in
2. Wardrobe (home)
3. Add item: capture
4. Add item: review tags
5. Item detail and edit
6. Get outfit: input
7. Get outfit: results
8. Saved outfits
9. Settings

Navigation: bottom tab bar with Wardrobe, Outfit, Saved, Settings.
